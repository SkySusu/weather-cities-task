# Weather Cities Task

Решение задания на Python без внешних пакетов.

Программа:

1. Загружает список городов из `cities.txt` в память.
2. Убирает повторы городов.
3. Для каждого уникального города получает данные через API `https://wttr.in/{City}?format=j1`.
4. Создаёт модель `WeatherData` с полями:
   - город;
   - текущая температура в градусах Цельсия;
   - страна.
5. Выводит погоду по каждому городу.
6. Группирует города по странам и выводит количество городов, среднюю, минимальную и максимальную температуру.

## Запуск

```bash
python3 weather_cities.py
```

Можно передать другой файл со списком городов:

```bash
python3 weather_cities.py path/to/cities.txt
```

## Пример вывода

```text
Weather by city:
Moscow, Russia +6 °C
Vienna, Austria +12 °C

Summary by country:
Austria — 1 city, avg: +12 °C, min: +12 °C, max: +12 °C
Russia — 1 city, avg: +6 °C, min: +6 °C, max: +6 °C
```

Фактические значения температуры зависят от текущего ответа API.
